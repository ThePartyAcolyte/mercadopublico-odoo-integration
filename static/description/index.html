Funcionalidades nativas para la gestión de licitaciones

Sincronización Total

Descarga diaria de Licitaciones Públicas (v1) y Compras Ágiles (v2) directamente desde la API oficial de ChileCompra, sin salir de Odoo.

Filtros de Precisión

Utiliza cruces automáticos con Categorías UNSPSC, palabras clave de tu negocio y etiquetas de productos para descartar el ruido y ver solo lo que te interesa.

Integración con CRM

Convierte una licitación apta en una Oportunidad de Odoo con un solo clic. El sistema asignará automáticamente tu Equipo de Ventas y el responsable configurado.

Notificaciones en Tiempo Real

Recibe alertas nativas dentro de un canal dedicado en Odoo Discuss cada vez que el sistema detecta un negocio compatible con tu empresa.

Configuración en minutos

Un asistente paso a paso te guiará para configurar tu ticket de API, tus rubros y tus palabras clave rápidamente.

  • Asistente gráfico e interactivo.
  • Vinculación con la API oficial.
  • Limpieza automática de datos desactualizados.

Requisitos del Sistema y Configuración

Dependencias de Python

Instale los paquetes requeridos en el entorno virtual de Odoo (venv):

pip install thefuzz requests pytz

Configuración en odoo.conf

Para garantizar que las tareas de sincronización masiva se ejecuten adecuadamente, se sugiere:

[options]
max_cron_threads = 2
limit_time_cpu = 600
limit_time_real = 1200

Tareas Programadas (Cron Jobs)

El módulo opera automáticamente a través de los siguientes trabajos programados.

Trabajo Automático Frecuencia Propósito
Importar Licitaciones (v1 Nocturno) Diaria (23:00) Descarga las licitaciones públicas del día.
Importar Compras Ágiles (v2) Cada 60 min Consulta la ventana temporal de compras ágiles recientes.
Analizar Licitaciones Nuevas Cada 2 min Procesa los lotes importados aplicando las reglas de filtrado.
Actualizar Estado Licitaciones Cada 2 horas Sincroniza cambios de estado en licitaciones vigentes.
Limpieza Automática Diaria (03:00) Purga registros descartados según el periodo de retención configurado.
