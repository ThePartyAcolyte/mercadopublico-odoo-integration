Funcionalidades nativas para la gestión de licitaciones

Sincronización Total

Descarga diaria de Licitaciones Públicas (v1) y Compras Ágiles (v2) directamente desde la API oficial de ChileCompra, sin salir de Odoo.

Filtros de Precisión

Utiliza cruces automáticos con Categorías UNSPSC, palabras clave de tu negocio y etiquetas de productos para descartar el ruido y ver solo lo que te interesa.

Integración con CRM

Convierte una licitación apta en una Oportunidad de Odoo con un solo clic. El sistema asignará automáticamente tu Equipo de Ventas y el responsable configurado.

Notificaciones en Tiempo Real

Recibe alertas nativas dentro de un canal dedicado en Odoo Discuss cada vez que el sistema detecta un negocio compatible con tu empresa.

Configuración en minutos

Un asistente paso a paso te guiará para configurar tu ticket de API, tus rubros y tus palabras clave rápidamente.

  • Asistente gráfico e interactivo.
  • Vinculación con la API oficial.
  • Limpieza automática de datos desactualizados.
